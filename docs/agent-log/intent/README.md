# Intent Records

Pre-action intent records for this repository, created from `templates/intent-log.md` before broad-scope, sensitive, architectural, externally visible, or difficult-to-reverse work.

- Record the exact intended action, rationale, risks, and alternatives **before** acting.
- Complete the Outcome section after execution, recording results and deviations honestly.
- If the action requires a human decision, record the question and stop until approval is explicit.
- Do not include secrets, credentials, or private-repository content.

Naming: `[YYYY-MM-DD]-[topic].md`.
